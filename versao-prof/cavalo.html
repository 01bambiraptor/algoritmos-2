A ideia em três palavras: escolhe, explora, desfaz

      
Backtracking é tentar um caminho, ir o mais longe possível e, quando dá errado, voltar só o último passo e tentar a próxima opção. Não recomeça do zero: desfaz o mínimo necessário.

      
O código é o cavalo.c do professor, com uma única mudança: as minas. Elas entram na matriz sol com o valor MINA (-2), então o isSafe dele já recusa essas casas sem mudar nada. E a parada vira movei == total (casas seguras) em vez de N * N.

      

        1. Escolhe: sol[next_x][next_y] = movei; marca a casa antes de chamar.

        2. Explora: solveKTUtil(next_x, next_y, movei + 1, ...) continua a partir dela.

        3. Desfaz: se voltou 0, o else faz sol[next_x][next_y] = -1; // backtracking e o for tenta o próximo salto.

Os 8 saltos do cavalo

      
Os vetores xMove e yMove guardam quanto o cavalo anda em linha e coluna em cada salto k. Trocar a ordem deles muda o caminho que o algoritmo testa primeiro, e pode mudar muito o número de chamadas.

      
int xMove[8] = { 2, 1, -1, -2, -2, -1,  1,  2 };
int yMove[8] = { 1, 2,  2,  1, -1, -2, -2, -1 };
