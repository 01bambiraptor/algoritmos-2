⚪ Resta Um em linha

Uma pedra pula por cima da vizinha e cai no buraco vazio do outro lado. A pedra pulada sai do jogo. Objetivo: deixar o menor número de pedras possível. Se travou com pedras demais, desfaz e tenta outro caminho. Isso é backtracking.

← é assim que o C enxerga o tabuleiro: o = pedra, - = vazio

A ideia antes do código

      
Pensa numa partida de damas onde você pode voltar no tempo. Você faz uma jogada, depois outra, e quando não tem mais o que fazer você anota quantas pedras sobraram. Aí volta uma jogada e tenta a outra opção daquele momento. Quando acabarem as opções daquele momento, volta mais uma. No fim você testou todas as partidas possíveis e sabe qual deixou menos pedras.

      
É isso que o restaUm faz. Ele é diferente do cavalo e do labirinto num ponto importante: não para na primeira solução. Ele quer a menor quantidade de pedras, então precisa olhar tudo. Por isso a função é void e não tem return 1 no meio do for.


      
O que não está escrito mas existe

      

        1. O valor inicial de cnt. A função só faz if (contador < cnt) cnt = contador;. Quem dá o primeiro valor é o main, com cnt = strlen(tab), ou seja, o tabuleiro inteiro cheio de pedras. Qualquer contagem real vai ser menor ou igual a isso, então o primeiro if já troca.


        2. O aux é o mesmo vetor em todas as chamadas. char *aux é um ponteiro. A chamada de baixo não recebe uma cópia: ela mexe no mesmo tabuleiro. Por isso as três linhas depois de restaUm(aux); são obrigatórias.


        3. A base da recursão. Não tem um if de parada. A recursão para sozinha quando nenhuma pedra consegue pular: os dois if de movimento dão falso pra todo i, o for termina e a função acaba.
      


      
As três palavras de sempre: escolhe, explora, desfaz

      

        1. Escolhe: aux[i] = '-'; aux[i+1] = '-'; aux[i+2] = 'o'; faz a jogada no tabuleiro.

        2. Explora: restaUm(aux); continua a partir desse tabuleiro novo.

        3. Desfaz: aux[i] = 'o'; aux[i+1] = 'o'; aux[i+2] = '-'; devolve o tabuleiro como estava, pra testar a próxima jogada.
